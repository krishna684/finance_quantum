# Data Directory

Raw data is **not** distributed with this repository. Follow the steps below to
obtain each dataset and place it in the expected location before running any scripts.

---

## 1. N24News (required for all experiments)

N24News is a multimodal news dataset of 61,218 New York Times articles with paired
images, captions, headlines, and abstracts (2010–2021).

**Download:**
Request access and download from the official release:
https://github.com/billywzh717/N24News

The download includes:
- `news/nytimes_dataset.json` — article metadata (headline, caption, abstract, section, URLs)
- `imgs/` — JPEG images keyed by `image_id`

**Setup:**
Place the downloaded archive so the structure is:

```
<anywhere on disk>/N24News/
    news/
        nytimes_dataset.json
    imgs/
        <image_id>.jpg
        ...
```

Then set the environment variable before running `scripts/build_index.py`:

```bash
N24NEWS_ROOT=/path/to/N24News python scripts/build_index.py
```

Or set it permanently in your shell / `.env` file:

```
N24NEWS_ROOT=/path/to/N24News
```

**Citation:**
```
Wang, Z., Liu, K., & Tang, B. (2022). N24News: A New Dataset for Multimodal News
Classification. In Proceedings of LREC 2022.
```

## 2. Fama-French Daily Factors (required for return labels)

Downloaded automatically by `scripts/build_labels.py` via `pandas_datareader`:

```python
web.DataReader("F-F_Research_Data_Factors_daily", "famafrench", ...)
```

No manual download needed. The script validates units (percent vs decimal) and
cross-checks against SPY returns (correlation threshold > 0.99).

**Source:** Kenneth French Data Library
https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html

---

## 3. CRSP Daily Stock File (required for firm-level portfolio analysis)

The portfolio and factor alpha analysis (`pipeline/portfolio.py`) requires the
CRSP Daily Stock File (DSF). This is a licensed dataset available through:

- **WRDS (Wharton Research Data Services):** https://wrds-www.wharton.edu/
- University library subscriptions (e.g., MU Library)

**Expected format:** CSV with columns:
```
permno, date, ret, retx, prc, vol, shrout, cfacpr
```

Place the file at `data/crsp_dsf.csv` or set `CRSP_DSF_PATH` in `.env`.

---

## 4. Pre-built data files (generated by pipeline scripts)

Once you have N24News and the French factors, run scripts in this order:

```bash
# Step 1: build article index (requires N24NEWS_ROOT)
python scripts/build_index.py
# -> data/index.parquet  (61,218 rows)

# Step 2: attach market return labels (downloads FF factors automatically)
python scripts/build_labels.py
# -> data/labeled.parquet  (10,206 finance rows)

# Step 3: score captions with FinBERT
python scripts/build_finbert_labels.py
# -> data/finbert_labeled.parquet  (10,206 rows + finbert_label + finbert_score)

# Step 4: embed images with CLIP ViT-B/32
python scripts/embed_images.py
# -> data/embeddings/n24news_finance.npz  (10,206 x 512 float32)
```

These intermediate files are not distributed because they depend on the N24News
image paths on your local machine.
